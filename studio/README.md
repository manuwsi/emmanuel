# Studio — sources des visuels du portfolio

Scripts qui génèrent les écrans, prototypes, images de partage et Reels du portfolio.
Ce dossier n'est pas mis en ligne sur le site (voir `.vercelignore`).

- `dailies/screens` — écrans de Dailies (HTML rendu en PNG), version anglaise, prototype cliquable, images de partage.
- `dailies/reel` — le Reel « DOT » (page HTML animée, rendue image par image avec flou de mouvement).
- `foil/screens` — écrans de l'appli Foil.
- `foil/blender` — rendus 3D de Foil (Blender).
- `proxy/gen.py` — transforme le prototype de Proxy en écrans rendus en direct dans le case.
- `proxy/world` — les images d'univers de Proxy : « L'onde » (shader, images fixes et film), la nuit et la macro du courriel (Blender).

Les vidéos finales, images sources et rendus ne sont pas versionnés ici (trop lourds).
